### CPU和GPU的区别：CPU是电脑里的中央处理器（Intel和AMD制造），而GPU（图形处理单元）原本是用来画游戏画面的，但几年前人们发现GPU的硬件架构非常适合训练超大规模神经网络——AI社区对算力有无尽的渴求，GPU恰好完美匹配了训练大神经网络所需的计算类型，这也是GPU在深度学习崛起中扮演重要角色的原因；NVIDIA卖了很多GPU，但高通、谷歌（TPU）等公司也在越来越多地制造专用硬件来驱动超大规模神经网络

> 除了这些开源技术工具，你也会经常听到 AI 工程师提到 CPU 和 GPU。这些词的意思：CPU 是你电脑里的计算机处理器——不管是台式机、笔记本还是云端的服务器。CPU 全称是"中央处理单元"，由 Intel、AMD 等公司制造，负责你计算机里大量计算任务。GPU 全称是"图形处理单元"。历史上 GPU 是用来处理图片的——玩视频游戏时，负责绘制精美画面的就是 GPU。但几年前我们发现，原本为图形处理设计的硬件，对于构建非常大的神经网络、非常大的深度学习算法来说也非常非常强大。由于需要训练非常大的深度学习或神经网络系统，AI 社区对更多计算能力有无尽的渴求来训练更大的神经网络。GPU 恰好完美匹配了训练超大神经网络所需的这种计算类型——这就是 GPU 在深度学习崛起中扮演重要角色的原因。NVIDIA 这家公司卖了很多 GPU，但其他公司——包括高通，以及谷歌做自己的 TPU——也越来越多地在制造专用硬件来驱动这些超大规模神经网络。
> In addition to these open source technical tools, you often also hear AI engineers talk about CPUs and GPUs. Here's what these terms mean. A CPU is the computer processor in your computer, whether it's your desktop, your laptop, or a computer server off in the cloud. CPU stands for central processing unit and CPUs are made by Intel and AMD and a few other companies. This does a lot of the computation in your computer. GPU stands for graphics processing unit. Historically, the GPU was made to process pictures. So if you play a video game, it's probably a GPU that is drawing the fancy graphics. But what we found several years ago was that the hardware that was originally built for processing graphics turns out to be very, very powerful for building very large neural networks, very large deep learning algorithms. Given the need to build very large deep learning or very large neural network systems, the AI community has had this insatiable hunger for more and more computational power to train big, grand, bigger neural networks. And GPUs have proved to be a fantastic fit to this type of computation that we need to have done to train very large neural networks. So that's why GPUs are playing a big role in the rise of deep learning. NVIDIA is a company that has been selling many GPUs, but other companies, including Qualcomm, as well as Google, making their own TPUs are increasingly making specialized hardware for powering these very large neural networks.

### 三种部署方案：云端部署——租用亚马逊AWS、微软Azure或谷歌GCP等第三方计算服务器；本地部署——自己购买服务器放在公司内部运行；边缘部署——把处理器直接放在数据采集的地方（比如自动驾驶汽车里的电脑、或者你家智能音箱里的语音识别处理器），优点是响应时间更快、减少需要传输到网络的数据量；每种方案都有各自的优缺点

> 最后你可能会听到"云端"和"本地部署"这两个词。云端部署指你租用计算服务器——比如从亚马逊 AWS、微软 Azure 或谷歌 GCP——用别人的服务器做你的计算。本地部署则是购买自己的计算服务器，在公司内部本地运行。详细探讨这两种方案的利弊超出了这个视频的范围。世界上的趋势是越来越多的走向云端部署，但如果你在线搜索，会找到很多文章讨论云端和本地部署的优缺点。还有最后一个你可能听到的词——边缘部署。如果你在造自动驾驶汽车，没有时间把数据从车上传到云端服务器来判断是否应该停车、再把指令传回车上——计算必须在车内的计算机上完成。这就是边缘部署——把处理器放在数据采集的位置，这样你可以快速处理数据做出决策，无需通过互联网传输数据到别处处理。看看你家的一些智能音箱，这也是边缘部署——有些语音识别任务是由内置在智能音箱里的处理器完成的。边缘部署的主要优势是可以提高系统的响应速度，同时减少需要通过互联网传输的数据量。但边缘、云端、本地部署之间也有很多利弊，你可以在线搜索了解更多。
> Finally, you might hear about cloud versus on-premises or, for short, on-prem deployments. Cloud deployments refer to if you rent compute servers, such as from Amazon's AWS or Microsoft's Azure or Google's GCP, in order to use someone else's servers to do your computation. Whereas an on-prem deployment means buying your own compute servers and running the servers locally in your own company. A detailed exploration of the pros and cons of these two options is beyond the scope of this video. A lot of the world is moving to cloud deployments. But if you search online, you find many articles talking about the pros and cons of cloud versus on-prem deployments. There is one last term you might hear about, which is edge deployments. If you are building a self-driving car, there's not enough time to send data from a self-driving car to a cloud server to decide if you should stop the car or not, and then send that message back to a self-driving car. So the computation has to happen usually in a computer right there inside the car. That's called an edge deployment, where you put a processor right where the data is collected so that you can process the data and make a decision very quickly without needing to transmit the data over the internet to be processed somewhere else. If you look at some of the smart speakers in your home as well, this too is an edge deployment where some, not all, but some of the speech recognition tasks is done by a processor that is built in right there into the smart speaker that is inside your home. The main advantage of edge deployments is it can increase response time of the system and also reduce the amount of data you need to send over the network. But there are many pros and cons as well about edge versus cloud versus on-prem deployments that you can also search online to read more about.
