## 一、Windows系统Claude Code安装部署

### Claude Code的Windows部署非常简单，只需两条命令即可完成。首先确保Node.js环境已部署好，然后打开终端，执行第一条命令`npm config set registry https://registry.npmmirror.com`将NPM软件源配置为国内镜像（因为连接国外网站速度较慢）。然后执行第二条命令`npm install -g @anthropic-ai/claude-code`正式安装Claude Code，等待约17秒即可完成。安装完成后执行`claude --version`验证，显示版本号（如2.1.185）即安装成功
